# @vx-oss/heroui-v2-accordion

Accordion display a list of high-level options that can expand/collapse to reveal more information.

Please refer to the [documentation](https://v2.heroui.com//docs/components/accordion) for more information.

## Installation

```sh
yarn add @vx-oss/heroui-v2-accordion
# or
npm i @vx-oss/heroui-v2-accordion
```
