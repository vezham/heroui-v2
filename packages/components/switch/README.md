# @vx-oss/heroui-v2-switch

The Switch component is used as an alternative between checked and not checked states.

Please refer to the [documentation](https://v2.heroui.com/docs/components/switch) for more information.

## Installation

```sh
yarn add @vx-oss/heroui-v2-switch
# or
npm i @vx-oss/heroui-v2-switch
```
