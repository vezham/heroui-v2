# @vx-oss/heroui-v2-scroll-shadow

A component that applies top and bottom shadows when content overflows on scroll.

Please refer to the [documentation](https://v2.heroui.com/docs/components/listbox) for more information.

## Installation

```sh
yarn add @vx-oss/heroui-v2-scroll-shadow
# or
npm i @vx-oss/heroui-v2-scroll-shadow
```
