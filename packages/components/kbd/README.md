# @vx-oss/heroui-v2-kbd

Keyboard key or kbd is a component to display which key or combination of keys performs a given action.

Please refer to the [documentation](https://v2.heroui.com/docs/components/kbd) for more information.

## Installation

```sh
yarn add @vx-oss/heroui-v2-kbd
# or
npm i @vx-oss/heroui-v2-kbd
```
