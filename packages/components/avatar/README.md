# @vx-oss/heroui-v2-avatar

The Avatar component is used to represent a user, and displays the profile picture, initials or fallback icon.

Please refer to the [documentation](https://v2.heroui.com/docs/components/avatar) for more information.

## Installation

```sh
yarn add @vx-oss/heroui-v2-avatar
# or
npm i @vx-oss/heroui-v2-avatar
```
