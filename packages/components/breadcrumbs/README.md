# @vx-oss/heroui-v2-breadcrumbs

Breadcrumbs display a hierarchy of links to the current page or resource in an application.

Please refer to the [documentation](https://v2.heroui.com/docs/components/breadcrumbs) for more information.

## Installation

```sh
yarn add @vx-oss/heroui-v2-breadcrumbs
# or
npm i @vx-oss/heroui-v2-breadcrumbs
```
